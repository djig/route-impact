## Major Bugs Fixed

### 1. Barrel Export Tracing
**Problem:** Tool couldn't trace through `export * from` or `export { X } from` statements.
**Fix:** Enhanced dependency graph to parse and follow export statements as dependencies.
**Impact:** Critical fix - real codebases use barrel files extensively.

### 2. Middleware and next.config as Global Files
**Problem:** Changes to middleware.ts or next.config.js weren't flagged as affecting all routes.
**Fix:** Added special handling to mark these as global files that affect all routes.
**Impact:** Essential for correctness.

### 3. Dependency Graph Scope
**Problem:** Graph only built from changed files, missing transitive dependencies.
**Fix:** Now builds graph from all route files + changed files to ensure complete tracing.
**Impact:** Major improvement in accuracy.

### 4. CSS Module Imports
**Problem:** CSS imports weren't being detected in the dependency graph.
**Fix:** Added regex patterns for CSS imports and included CSS extensions.
**Impact:** Important for style-driven changes.

### 5. Pages Router `_app` and `_document`
**Problem:** Not treated as global files affecting all pages.
**Fix:** Added to global files list.
**Impact:** Correct behavior for Pages Router projects.

## Analyzer Architecture Improvements

**Before:**
- Only looked at files in `app/` or `pages/` directories from changed set
- Couldn't trace dependencies back through imports
- No barrel export support

**After:**
- Collects ALL route files in project first
- Builds complete dependency graph
- Filters routes whose files are in affected set
- Traces import chains from routes back to changed files
- Handles barrel exports, CSS imports, and path aliases
